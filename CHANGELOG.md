## [1.0.0] - 2024-01-01

### Added
- Laravel 12 framework
- Inertia.js with React frontend
- Module-based architecture using nwidart/laravel-modules
- E-commerce features (products, cart, checkout)
- Admin panel with role-based access control
- Spatie Laravel Permission integration
- Spatie Media Library for file management
- Laravel Socialite for social authentication
- SSLCommerz payment gateway integration
- Laravel Reverb for WebSocket support
- Server-side rendering (SSR) support
- Tailwind CSS with Radix UI components
- Comprehensive helper functions
- Database migrations and seeders
- Testing setup with PHPUnit
